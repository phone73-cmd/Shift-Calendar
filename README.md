# 4조 2교대 달력

기준일 하나만 설정하면 4개 조(A/B/C/D)의 근무(주간/야간/비번/휴무)를 자동으로 계산해 보여주는 월간 교대근무 달력입니다. 순수 HTML/CSS/JS로만 만들어져 있어 별도 빌드 과정 없이 `index.html`을 열면 바로 동작합니다.

## 사용법

- `index.html`을 브라우저로 열면 바로 실행됩니다.
- 상단에서 내 조(A/B/C/D)를 선택하면 달력 전체가 해당 조 기준으로 다시 계산됩니다.
- 우측 상단 ⚙ 아이콘에서 기준 날짜 · 기준 조 · 그날의 근무를 입력하면 전체 패턴이 그 값에 맞춰 재계산됩니다.
- 날짜 아래 코드(예: `BC`)는 그날 주간 근무 조 + 야간 근무 조를 의미합니다.

## GitHub Pages로 배포하기

저장소 설정(Settings → Pages)에서 `main` 브랜치의 루트 디렉터리를 배포 소스로 지정하면 `index.html`이 그대로 웹페이지로 서비스됩니다.

## 근무 패턴

기본값은 2026년 9월 1일 기준 B조 주간·C조 야간(즉 A조 휴무, D조 비번)이며, 이후 조마다 하루씩 밀려 `주간 → 야간 → 비번 → 휴무` 4일 주기로 반복됩니다. 실제 스케줄과 다르면 설정 화면에서 언제든 보정할 수 있습니다.
